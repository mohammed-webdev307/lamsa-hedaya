إضافة إعدادات المتجر للوحة التحكم

1) ارفع ملفات المشروع إلى GitHub.
2) قبل استخدام زر "إعدادات المتجر" افتح Supabase > SQL Editor.
3) شغّل محتوى الملف SETUP_STORE_SETTINGS.sql مرة واحدة فقط.
4) افتح /admin وسجل الدخول ثم اضغط "إعدادات المتجر".

يمكن التحكم في:
- اسم المتجر والشعار النصي
- رقم واتساب والهاتف
- البريد وإنستغرام
- الموقع
- العملة واسمها
- ساعات العمل
- وصف الفوتر

إذا لم يتم تشغيل SQL سيبقى الموقع يعمل بالقيم القديمة، لكن حفظ الإعدادات لن ينجح.
